Project Title: SDG-02 
Track/Theme: Disaster Management System with Satellite Mapping and Natural-Calamity Detection
Project Description: 
An AI-powered disaster management platform that combines satellite imagery, weather data, sensors, and geospatial mapping to detect hazards, assess their impact, identify high-risk areas, and prioritize emergency response. Agentic AI helps plan evacuation routes and resource allocation, with simulations enabling authorities to test and improve decisions before real-world deployment.
